## 🎯 Focus

- **游戏架构实践**：数据驱动配置、分层状态机（HFSM）、服务容器组合根，领域逻辑与网络层彻底解耦
- **Roguelike / ARPG 玩法实现**：回合制战斗循环、卡牌构筑、纵深阵型与敌人意图系统
- **GameJam 工程化**：轻量启动框架，开箱即用，覆盖 90% 通用需求，半小时内通读全部源码
- **.NET 桌面工具**：零依赖 WinForms / WPF 应用，P/Invoke 与 GDI+ 实战
